# Logic and Mathematics

## Part 1: Overview

### What is logic?
- Aim: develop a language to model real situations encountered in computer science
- Modeled so we can reason formally
- Focus: logical structure of sentences
- Hence we build on propositions

### What is propositional logic?
- First step of logic
- Built from propositions
- Combined using logical connectives, connectives form expressions
- Final outcome: logical arguments

### Where does it lead?
- Arguments expressed in CNF or DNF
- CNF = product of sums (Boolean algebra)
- CNF helps check tautology, satisfiability, etc.
- Leads formally into SAT solvers
- Then onward to SMT solvers

### Roadmap
1. Propositional logic (current)
2. First-order logic
3. SAT
4. SMT

## Part 2: Propositional Logic

### 1. Propositions and connectives
- Start with propositions
- Combine using logical connectives
- Connectives build expressions
- Study how each connective works
- Express sentences using different connectives

### 2. Propositional formulas
- Such expressions are called propositional formulas

### 3. Logical equivalence
- Establish what logical equivalence means

### 4. Logical arguments
- Connects everything above
- Multiple expressions form premises
- Propose a conclusion (consequent)
- Check whether the conclusion holds
- Methods: natural deduction, contradiction, others
- Core idea: premises plus conclusion, test if conclusion holds

### 5. Connection to CNF and DNF
- Arguments expressed in CNF or DNF
- CNF = product of sums (Boolean algebra)
- Helps decide tautology, satisfiability
- Bridge to SAT and SMT solvers
